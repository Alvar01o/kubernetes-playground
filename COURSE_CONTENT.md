## 🔧 Quick Reference - Comandos Esenciales

### Gestión de Clústeres

```bash
# Ver contextos y cambiar de cluster
kubectl config get-contexts
kubectl config use-context <context-name>
kubectl config current-context

# Información del cluster
kubectl cluster-info
kubectl get nodes
kubectl describe node <node-name>
```

### Pods (Unidad mínima)

```bash
# Crear y ver pods
kubectl run my-pod --image=nginx
kubectl get pods [-A]                          # -A = all namespaces
kubectl describe pod <pod-name>
kubectl logs <pod-name> [-f]                   # -f = follow

# Acceder a un pod
kubectl exec -it <pod-name> -- /bin/bash
kubectl port-forward pod/<pod-name> 8080:8080
kubectl cp <pod-name>:/path/to/file ./local
```

### Deployments (Escalado y actualizaciones)

```bash
# Crear deployment
kubectl create deployment <name> --image=<image> --replicas=3
kubectl apply -f deployment.yaml

# Escalado manual
kubectl scale deployment <name> --replicas=5

# Actualizaciones
kubectl set image deployment/<name> <container>=<image>
kubectl rollout status deployment/<name>
kubectl rollout history deployment/<name>
kubectl rollout undo deployment/<name>

# Ver recursos utilizados
kubectl top pods
kubectl top nodes
```

### Services (Exposición de aplicaciones)

```bash
# Crear service (acceso interno)
kubectl expose deployment <name> --type=ClusterIP --port=80

# Service con acceso externo
kubectl expose deployment <name> --type=NodePort --port=80

# Ver services
kubectl get svc
kubectl get endpoints <service-name>

# Port forwarding
kubectl port-forward svc/<name> 8080:80
```

### Configuración y Secretos

```bash
# ConfigMaps (configuración)
kubectl create configmap <name> --from-literal=key=value
kubectl get configmap
kubectl describe configmap <name>

# Secrets (datos sensibles)
kubectl create secret generic <name> --from-literal=password=123
kubectl get secrets
kubectl describe secret <name>

# Desde archivos
kubectl create configmap <name> --from-file=config.yml
kubectl create secret generic <name> --from-file=tls.key --from-file=tls.crt
```

### Debugging y Troubleshooting

```bash
# Información detallada
kubectl describe <resource> <name>
kubectl get <resource> -o yaml
kubectl get <resource> -o wide

# Logs
kubectl logs <pod>
kubectl logs <pod> --previous
kubectl logs -f <pod>                         # Follow logs
kubectl logs <pod> -c <container-name>        # Contenedor específico

# Eventos y estado
kubectl get events
kubectl get events --field-selector involvedObject.name=<pod>

# Información del API
kubectl api-resources
kubectl explain pod
kubectl explain pod.spec
```

### Monitoreo

```bash
# Métricas de recursos
kubectl top nodes
kubectl top pods
kubectl top pod <pod-name> --containers

# Ver cambios en tiempo real
kubectl get pods -w
kubectl get deployment -w
kubectl rollout status deployment/<name> --watch

# Eventos
kubectl get events -A --sort-by='.lastTimestamp'
```

## 🚀 Quick Start - Primeros Pasos

```bash
# 1. Instalar Minikube
curl -LO https://github.com/kubernetes/minikube/releases/download/latest/minikube-linux-amd64
sudo install minikube-linux-amd64 /usr/local/bin/minikube

# 2. Iniciar cluster local
minikube start --cpus=4 --memory=8192

# 3. Crear primer deployment
kubectl create deployment hello-world --image=nginx

# 4. Ver pods creados
kubectl get pods

# 5. Exponer servicio
kubectl expose deployment hello-world --type=NodePort --port=80

# 6. Acceder a la aplicación
minikube service hello-world

# 7. Ver logs
kubectl logs deployment/hello-world

# 8. Escalar
kubectl scale deployment hello-world --replicas=3

# 9. Ver todos los pods
kubectl get pods

# 10. Dashboard
minikube dashboard
```

## 💡 Conceptos Clave Explicados

### Pod
- Unidad mínima en Kubernetes
- Puede contener uno o múltiples contenedores
- Comparten red (mismo IP) y almacenamiento

**Comando:** `kubectl get pods`

### Deployment
- Gestiona replicas de pods
- Permite actualizaciones sin downtime
- Mantiene estado deseado

**Comando:** `kubectl create deployment <name> --image=<image> --replicas=3`

### Service
- Expone pods dentro o fuera del cluster
- Load balancer interno
- Descubrimiento de servicios

**Comando:** `kubectl expose deployment <name> --type=LoadBalancer`

### Namespace
- Aislamiento lógico del cluster
- Multitenancy
- Resource quotas

**Comando:** `kubectl create namespace <name>`

### StatefulSet
- Para aplicaciones con estado
- Identidades de pods persistentes
- Volúmenes persistentes

**Comando:** `kubectl apply -f statefulset.yaml`

### Ingress
- Router de capa 7 (HTTP/HTTPS)
- Múltiples dominios y paths
- Reemplaza LoadBalancers para muchos servicios

**Comando:** `kubectl apply -f ingress.yaml`
